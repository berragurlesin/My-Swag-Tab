Hi everyone, welcome to the SWAG tab!
This new tab page is for people who love to customize things and reflect their style even in their computer. I am one of them, that's why I made this project. Now I'm gonna explain every feature of the tab:
## Features~
* Of course there is a search box which you can paste a link or write whatever you like, use it for search cool things!
* A clock I costumized, I chose the digits and uploaded them. Who doesn't love a sparkly clock?
* If I'm creating a new tab page, I needed a shortcuts box for quick access to the most visited sites or whatever, one that looks shiny and fetches the app's icons. You can delete them when you no longer need them. 
* Stickers that matchs your style! I've set up some default stickers and the positions but you can delete them, move them anywhere you want and add new ones if you like. Making it look good entirely up to you. You can also adjust the dimensions by right-clicking.
* A space image (or video) and description from NASA every day. I used APOD API so when an image arrives, it appears directly on the box; on days when a video comes in, you'll be able to watch it by clicking. You can also move the box wherever you want. Cool huh?
* There is a settings button in the bottom, right corner. It lets you change the background (you can choose from the avesome default ones I've added or upload yours) and you can also add or remove stickers from here (apart from the limited edition one, that one will always be there tp make you feel special)
* Would you like to add your name on your new tab? You can even place it inside those aesthetic red sticker. Just type whatever you want into the "hello my name is.." stciker (letters only) and the size will adjust based on the leght of the text! Maximum 15 letters.
* Woah, this part is important. As people, we need motivation. SWAG tab helps you out with this too. There is a box where you can upload any quote you like to keep yourself motivated! I think you'll find it useful.
* Wanted to add, there are hoovers on some of the buttons, and the general button color is a cute yellow. I think these add an aesthetic touch.

In short, SWAG tab is a cool new tab page. Designed so you can personalize it to your style ♡

## Setup~
If you want to set SWAG tab as your default new tab page, follow this:
* Copy the live demo URL
* Install a custom new tab extension for your browser (it mostly called "custom new tab URL, new tab override" etc.)
* Open the extension settings, paste the URL, and save.

See, it's that easy to use on your computer!
